# Crochet Pattern ML

A machine learning project that classifies crochet pattern difficulty and provides personalised recommendations using data from the Ravelry API.

## Project Structure
- `data/` — raw and processed datasets
- `notebooks/` — exploratory data analysis
- `src/` — source code
- `tests/` — unit tests
- `configs/` — configuration files

## Tech Stack
- Python 3.12
- DVC (data versioning)
- MLflow (experiment tracking)
- FastAPI (model serving)
- Docker (containerization)
- AWS (cloud deployment)

## Setup
```bash
pip install -r requirements.txt
```
